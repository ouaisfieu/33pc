# 33 % — Le gouvernement du tiers

Récit interactif et sourcé sur le gouvernement fédéral belge De Wever (coalition « Arizona »),
faits arrêtés au **30 septembre 2026**.

Un tiers des chômeurs exclus devaient retrouver un emploi. Plus d'un tiers de la hausse militaire
repose sur les avoirs russes gelés. Le temps partiel minimum passe d'un tiers à un dixième.
Sept chapitres, huit devinettes (placez le curseur, puis comparez avec la réalité), un indice
d'optimisme final, 74 sources numérotées dans l'ordre d'apparition.

## Principes

- Chaque fait est sourcé ; les jugements sont signalés (« Notre lecture »).
- Chaque chapitre donne son meilleur argument à la majorité (« Ce que répond la majorité »).
- Les apartés « Rire jaune » sont satiriques, sur des faits vrais ; aucune citation n'est inventée.
- Site anonyme : aucune signature, aucun cookie, aucun traceur, aucune police ni ressource externe,
  `referrer` désactivé. Les réponses aux devinettes ne quittent pas le navigateur.

## Fichiers

| Fichier | Rôle |
|---|---|
| `index.html` | Le récit complet (fonctionne sans JavaScript : les réponses sont alors affichées d'emblée) |
| `404.html` | Page d'erreur (chemin de base détecté automatiquement, rien n'est codé en dur) |
| `assets/style.css`, `assets/app.js` | Mise en forme (clair/sombre) et interactions |
| `sources.json` | Les sources, numérotées, en données ouvertes |

HTML/CSS/JS sans dépendance ni étape de build. Publication : copier le contenu de ce dossier à la
racine du dépôt, puis activer GitHub Pages (branche principale, racine). `.nojekyll` est inclus.
